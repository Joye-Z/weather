# 智能天气信息面板

一个基于HTML、CSS和JavaScript开发的智能天气查询应用，提供美观的天气信息展示和实用的生活建议功能。

## 功能特性

### 基础功能
- ✅ 城市天气查询（支持高德天气API）
- ✅ 实时温度、天气状况显示
- ✅ 风力风向、湿度信息展示
- ✅ 响应式设计，支持移动端

### 扩展功能
- ✅ 生活建议系统（根据天气生成穿衣、出行、运动建议）
- ✅ 城市搜索联想（输入时动态提示城市名称）
- ✅ 动态背景切换（根据天气状况自动调整背景）

## 使用说明

### 1. 获取高德API密钥
1. 访问[高德开放平台](https://lbs.amap.com/)
2. 注册账号并创建应用
3. 获取Web服务API Key
4. 在 `script.js` 文件中替换 `AMAP_API_KEY` 变量：

```javascript
const AMAP_API_KEY = '你的实际API密钥';
```

### 2. 本地运行
1. 确保所有文件在同一目录下
2. 用浏览器打开 `index.html` 文件
3. 输入城市名称查询天气

### 3. 部署到服务器
- 将所有文件上传到Web服务器
- 确保服务器支持HTTPS（高德API需要）

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **图标**: Font Awesome 6.0
- **API**: 高德地图天气API
- **设计**: 响应式设计，CSS Grid/Flexbox布局

- Firefox 55+

## 注意事项

1. **API密钥**: 必须使用有效的高德API密钥才能正常使用
2. **HTTPS**: 生产环境需要HTTPS协议
3. **请求限制**: 注意高德API的调用频率限制
4. **错误处理**: 应用包含完整的错误处理机制
